# Follower Finder updates

<img src="assets/avatar.jpg" alt="Follower Finder profile picture" width="160">

Official update channel for the Follower Finder Grok Bot. Installed bots check `VERSION` here at setup and weekly, and apply newer builds with `src/updater.py` (snapshot first, roll back on failure, owner data never touched).

Follower Finder is a subscription: $4.49/month, or $8.99/month bundled with Bot Terminator, via https://empressheavy.com/subscribe/.

- `VERSION` – current published version
- `SKILL.md` – the getting-started skill
- `src/`, `hive/`, `templates/`, `tools/`, `config/` – bot code
- `routines/weekly-update-check.md` – the weekly update routine

Only this repo (github.com/EmpressHeavy/FollowerFinderUpdates, branch main) is a valid update source. No user data lives here.
